## 🌟 Introduction

**WhatsLink** ek **100% FREE** online earning platform hai. Users WhatsApp link karte hain aur **600 coins** (₨ 300) kamaate hain.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📱 WhatsApp Linking | 24 hours session, earn 600 coins |
| 💰 Instant Earnings | Coins add immediately after linking |
| 📋 Tasks System | Complete tasks to earn extra coins |
| 👥 Referral Program | Invite friends and earn bonuses |
| 💬 WhatsApp Web Clone | Full WhatsApp interface in browser |
| 📊 Dashboard | Track earnings and coins |

## 💰 Earning Structure

## 🏗️ Tech Stack

### Backend
- **Node.js** - Runtime
- **Express.js** - Web framework
- **MongoDB Atlas** - Database (FREE)
- **Redis (Upstash)** - Sessions (FREE)
- **Socket.io** - Real-time
- **whatsapp-web.js** - WhatsApp integration

### Frontend
- **HTML5 + CSS3 + JavaScript**
- **Socket.io Client** - Real-time

### Hosting (All FREE)
- **Render** - Backend
- **Vercel** - Frontend
- **GitHub** - Code hosting
- **UptimeRobot** - Monitoring
